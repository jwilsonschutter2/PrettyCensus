How to get a Census API key

    

      
The U.S. Census Bureau provides API keys through its official key signup page. Use your key in API calls with &key=YOUR_KEY.

      
    
        
  1. Open the U.S. Census Data API key signup page.
    2. 
        
  2. Enter the requested contact information, including your email address.
    3. 
        
  3. Agree to the terms of service and submit the request.
    4. 
        
  4. Check your email for the Census Data API key message.
    5. 
        
  5. Copy the key into the API Key field in PrettyCensus and click Save.
